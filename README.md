# 🛡️ SAVIOUR

> Never let the door close on you.

SAVIOUR is an AI-powered career assistant that helps students organize internships, placement drives, hackathons, scholarships, and interviews directly from Gmail.

Instead of searching through hundreds of emails, SAVIOUR extracts important opportunities, deadlines, and reminders into one intelligent dashboard.

## ✨ Features

- 📧 Smart Career Inbox
- 📅 Deadline Tracking
- 🤖 AI-Powered Summaries
- 🔔 Smart Reminders
- 📊 Career Dashboard
- 🔒 Privacy-First Design

## 🛠 Tech Stack

- Next.js
- FastAPI
- PostgreSQL
- TypeScript
- Tailwind CSS
- Gmail API
- Google OAuth
- REST APIs

## 🎯 Mission

Help students stay organized, reduce missed opportunities, and never let an important deadline slip away.
